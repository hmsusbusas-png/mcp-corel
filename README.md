# mcp-corel

MCP-сервер, который управляет CorelDRAW из Claude Desktop через COM: документы и страницы, фигуры, линии, текст, импорт картинок, правка объектов, группировка, выравнивание, экспорт в десять форматов и запуск макросов.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `corel_status` | путь установки, версия, открытые документы |
| `corel_open` | открыть файл или создать документ нужного размера |
| `corel_close` | закрыть активный документ, с сохранением или без |
| `corel_pages` | список, добавление, удаление и переход по страницам, размер и ориентация листа |
| `corel_shape` | прямоугольник (со скруглением), эллипс, многоугольник, звезда с заливкой и обводкой |
| `corel_line` | отрезок, ломаная или замкнутый контур по точкам |
| `corel_text` | строка текста или абзацный текст с переносом, шрифт, размер, цвет, выравнивание |
| `corel_import` | импорт PNG, JPG, SVG, PDF, AI, EPS, DXF с размещением и масштабом |
| `corel_list` | объекты страницы: id, тип, имя, положение, размер, текст |
| `corel_modify` | перемещение, размер, поворот, заливка, обводка, текст, порядок, дублирование, удаление по id |
| `corel_group` | группировка и разгруппировка |
| `corel_align` | выравнивание по листу по горизонтали и вертикали |
| `corel_export` | лист целиком или выбранные объекты в PNG (с прозрачностью), JPG, WEBP, BMP, TIF, SVG, PDF, EPS, AI, DXF |
| `corel_save` | сохранить как CDR |
| `corel_macro` | запустить установленный макрос VBA или GMS |

Все размеры и координаты задаются в миллиметрах. Отсчёт идёт от левого нижнего угла листа, и `x`, `y` фигуры означают её левый нижний угол.

Все вызовы COM выполняются в одном отдельном потоке. Если CorelDRAW висит на диалоге, сервер вернёт понятную ошибку по таймауту, а следующий вызов переподключится. Ожидание запуска CorelDRAW до 120 с, обычной операции до 60 с, экспорта до 180 с.

## Установка

Нужны Windows, [uv](https://docs.astral.sh/uv/), Claude Desktop и CorelDRAW. Проверено на CorelDRAW 2024 (версия 25).

```powershell
git clone https://github.com/hmsusbusas-png/mcp-corel C:\mcp\mcp-corel
cd C:\mcp\mcp-corel
uv sync
```

## Подключение к Claude Desktop

Settings, Developer, Edit Config. Путь к uv нужен полный, его покажет `where.exe uv`.

```json
{
  "mcpServers": {
    "corel": {
      "command": "C:\\Users\\<имя>\\.local\\bin\\uv.exe",
      "args": ["run", "--directory", "C:\\mcp\\mcp-corel", "python", "-m", "corelmcp"]
    }
  }
}
```

После правки полностью закройте Claude Desktop из трея и запустите снова.

## Проверка

```powershell
uv run pytest
uv run pytest -m live
```

Вторая команда рисует тестовый документ в установленном CorelDRAW, экспортирует его во все форматы и закрывает без сохранения.
